# สกิล Q และท่าไม้ตาย (E) ของฮีโร่แต่ละตัว

ตัวเลขทั้งหมดดึงมาจาก `Assets/Game/CombatConfigs/*.asset` (ค่าพื้นฐาน ก่อนบวกโบนัสจากการ์ดพร/เลเวล)
ส่วนพฤติกรรมของสกิลอยู่ใน `Assets/Scripts/Combat/PlayerSkills.cs`, `ShieldWall.cs` และ `SkillArea.cs`

- **Q** = สกิล (Active) · **E** = ท่าไม้ตาย (Ultimate) · **Tab** = สลับท่วงท่า (ดาฟนีเท่านั้น)
- บนมือถือ กดปุ่มเพื่อร่ายใส่ศัตรูที่ใกล้ที่สุดอัตโนมัติ หรือลากปุ่มเพื่อเล็งเอง
- ระยะเล็งสูงสุดของสกิลที่ต้องเลือกจุด = 6 หน่วย ทุกตัว
- ดาเมจทุกสกิลคูณกับบัฟพลังโจมตีที่มีอยู่ตอนนั้น
- ถ้ามีการ์ดพรที่ให้โล่ตอนใช้สกิล Q จะได้โล่ตาม % ของ HP สูงสุดทุกครั้งที่กด Q
- ใช้สกิลไม่ได้ระหว่างโดนกระแทกลอย (Knockup)

---

## 1. แทงค์ (Tanky)
HP 120 · ตัวป้องกันระยะไกล แปลงดาเมจที่ทำเป็นโล่ (2.5% ของดาเมจ, โล่สูงสุด 30) มีโล่เล็ก 4 อันหมุนรอบตัวตลอดเวลา

### Q — กำแพงโล่ดวงดาว (Astral Shield Wall)
| ค่า | |
|---|---|
| คูลดาวน์ | 12 วินาที |
| การเล็ง | เลือกทิศทาง |
| อยู่ได้ | 3 วินาที |

- ตั้งกำแพงยาว 3 หน่วย ห่างจากตัว 1.2 หน่วยไปในทิศที่เล็ง ด้านบนของรูปกำแพงหันเข้าหาแทงค์เสมอ
- **บล็อกกระสุนศัตรู** ที่พุ่งเข้ามาจากด้านหน้ากำแพง (กระสุนที่ทะลุสิ่งกีดขวางได้จะไม่ถูกบล็อก)
- ไม่ได้กันตัวศัตรูที่เดินผ่าน กันแค่กระสุน
- ถ้าแทงค์ยืนอยู่ด้านหลังกำแพง (ไม่เกิน 6 หน่วย และอยู่ในความกว้างของกำแพง) ได้ **ป้องกัน +15%**
- ระหว่างกำแพงตั้งอยู่ โล่เล็กที่หมุนรอบตัวจะซ่อนไว้

### E — อุกกาบาตดวงดาว (Astral Meteor)
| ค่า | |
|---|---|
| คูลดาวน์ | 30 วินาที |
| การเล็ง | เลือกจุดบนพื้น (ไกลสุด 6 หน่วย) |
| ดาเมจ | 100 ในรัศมี 2.4 หน่วย |

- อุกกาบาตตกลงมาหลังร่าย 0.5 วินาที
- ศัตรูที่โดน **ถูกตรึง 2 วินาที** และ **พลังโจมตีลด 20% นาน 3 วินาที**

## 2. เงา (Shadow)
HP 110 · นักสู้คุไน ตีโดนแล้วสะสมสแต็ก (สูงสุด 10) ได้ความเร็วโจมตี +3% ต่อสแต็ก สแต็กหายถ้าไม่โดนเกิน 3 วินาที คุไนเจาะเกราะ 20%

### Q — เงาเร่งเครื่อง (Shadow Overdrive)
| ค่า | |
|---|---|
| คูลดาวน์ | 18 วินาที |
| การเล็ง | ลากเลือกทิศที่จะพุ่งไป |
| ระยะเวลาบัฟ | 2 วินาที |

- **พุ่งถอยหลัง** 2 หน่วย ใน 0.2 วินาที ใช้หนีออกจากวงศัตรู
- ความเร็วโจมตี **+20%** นาน 2 วินาที
- ระหว่างนั้นการโจมตีปกติ **ยิงคุไน 3 อันแบบพัด** (กว้าง 30°)

### E — ประหารเงา (Shadow Execution)
| ค่า | |
|---|---|
| คูลดาวน์ | 30 วินาที |
| การเล็ง | ไม่ต้องเล็ง |
| ดาเมจ | 70 ต่อศัตรู 1 ตัว |

- กระโดดขึ้น แล้วหลัง 0.5 วินาทีคุไน 3 อันตกใส่ **ศัตรูทุกตัวที่มองเห็นบนจอ**
- เป็นการโจมตีด้วยคุไน จึงเจาะเกราะและนับสแต็กด้วย

## 3. นักมายากล (Magician)
HP 115 · ยิงไพ่เด้งไปหาศัตรูตัวถัดไปได้ 3 ครั้ง (รัศมีเด้ง 3 หน่วย) หลบการโจมตีได้ 12%

### Q — กับดักมายา (Illusion Trap)
| ค่า | |
|---|---|
| คูลดาวน์ | 8 วินาที |
| การเล็ง | ไม่ต้องเล็ง (วางใต้เท้า) |
| ดาเมจ | 50 ในรัศมี 2.4 หน่วย |

- วางไพ่กับดักไว้ที่พื้น อยู่ได้ 8 วินาที
- ระเบิดเมื่อศัตรูเข้าใกล้ภายใน 0.8 หน่วย
- ศัตรูที่โดน **ถูกกระแทกลอย 0.7 วินาที** (ขยับและโจมตีไม่ได้)

### E — แจ็กพอต (Jackpot)
| ค่า | |
|---|---|
| คูลดาวน์ | 30 วินาที |
| การเล็ง | ไม่ต้องเล็ง |
| ดาเมจรวม | 180 ในรัศมี 2.4 หน่วย |

- สร้างพายุไพ่หมุนตรงจุดที่ยืน นาน 4 วินาที ทำดาเมจทุก 0.5 วินาที (8 ครั้ง ครั้งละ 22.5)
- พร้อมกัน **วาร์ปตัวเองออกไปจุดที่ปลอดภัย** ไกลสุด 6 หน่วย ทิ้งพายุไว้ที่เดิม

## 4. แม่มดพยากรณ์ (Oracle Witch)
HP 110 · ยิงลูกเวทช้าที่ระเบิดเมื่อโดน (รัศมี 1.6) ทะลุสิ่งกีดขวาง **ดาเมจทุกอย่างของแม่มดไม่สนค่าป้องกัน**

### Q — สนามบิดเบือนเวลา (Time Distortion Field)
| ค่า | |
|---|---|
| คูลดาวน์ | 12 วินาที |
| การเล็ง | เลือกจุดบนพื้น (ไกลสุด 6 หน่วย) |
| อยู่ได้ | 3.5 วินาที |

- สร้างสนามรัศมี 1.6 หน่วย ศัตรูในสนาม **ช้าลง 60%**
- ไม่มีดาเมจ เป็นสกิลควบคุมล้วน ๆ (ออกจากสนามแล้วหายช้าทันที)

### E — คำพิพากษาเงียบงัน (Silent Judgment)
| ค่า | |
|---|---|
| คูลดาวน์ | 30 วินาที |
| การเล็ง | ไม่ต้องเล็ง |
| ดาเมจ | 75 ต่อศัตรู 1 ตัว |

- หลัง 0.5 วินาที หอกเวทแทงลงใส่ **ศัตรูทุกตัวที่มองเห็นบนจอ**
- **โดนแน่นอน** ศัตรูหลบไม่ได้ และไม่สนค่าป้องกัน

## 5. ดาฟนี (Daphne)
HP 120 · มีสองท่วงท่า สลับด้วย Tab (คูลดาวน์ 3 วินาที)
- **สุริยะ** (เริ่มต้น): ยิงลูกไฟระเบิดเป็นวง ทำให้ติดไฟ 4 ดาเมจ/วินาที นาน 3 วินาที
- **จันทรา**: ยิงลูกเวทเดี่ยว 25 ดาเมจ
- ตอนสลับได้บัฟ 15% นาน 3 วินาที: เข้าสุริยะได้พลังโจมตี, เข้าจันทราได้ความเร็วเดิน

### Q — ควบคุมฟากฟ้า (Celestial Control) — เปลี่ยนตามท่วงท่า
| ค่า | |
|---|---|
| คูลดาวน์ | 9 วินาที (ใช้ร่วมกันทั้งสองท่วงท่า) |
| ดาเมจ | 45 |

- **ท่วงท่าสุริยะ** (ไม่ต้องเล็ง): ระเบิดรอบตัวรัศมี 1.4 หน่วย **ผลักศัตรูออกไป 1.5 หน่วย**
- **ท่วงท่าจันทรา** (เลือกทิศทาง): ยิงลูกเวทผูกมัด โดนตัวแรก **ตรึง 1.5 วินาที**

### E — สุริยุปราคา (Eclipse)
| ค่า | |
|---|---|
| คูลดาวน์ | 35 วินาที |
| การเล็ง | ไม่ต้องเล็ง |
| ดาเมจ | 60 ต่อศัตรู 1 ตัว |

1. ลูกอาทิตย์และลูกจันทร์ลอยมารวมกันเหนือหัว ใช้เวลา 1.2 วินาที
2. พอรวมกัน **ฟื้น HP 20**
3. วงคลื่นแผ่ออกจากตัว (เร็ว 9 หน่วย/วินาที) จนพ้นแผนที่ โดน **ศัตรูทุกตัวในด่าน** แม้อยู่นอกจอ
4. ทิ้งสนามดวงดาวไว้ที่จุดร่าย รัศมี 2.3 หน่วย นาน 3 วินาที ทำ 4 ดาเมจทุก 0.5 วินาที
